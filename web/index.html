⚙ Einstellungen

So findest du deinen Login-Token:
  1. In CT anmelden.
  2. Oben rechts auf das eigene Nutzerbild klicken.
  3. Mein Profil wählen.
  4. Login-Token anzeigen anklicken.
  5. Den langen Token-Text kopieren und hier einfügen.

🔒 Der Login-Token wird nur im Arbeitsspeicher gehalten und beim Beenden verworfen. Teile den Token nicht mit anderen Personen.

Willkommen bei CT Gruppenhierarchie

Diese unabhängige Anwendung visualisiert die Gruppenstruktur einer vom Nutzer angegebenen CT-Instanz.

Read-only: Die Anwendung verändert keine Daten in CT.

Der Login-Token wird nicht dauerhaft gespeichert. Es gibt keine Telemetrie und keinen vom Entwickler betriebenen Server für CT-Daten.

Unabhängiges Community-Tool. Keine offizielle Anwendung von ChurchTools Innovations GmbH.
