Willkommen bei CT Gruppenhierarchie

Diese unabhängige Anwendung visualisiert die Gruppenstruktur einer vom Nutzer angegebenen CT-Instanz.

Read-only: Die Anwendung verändert keine Daten in CT.

Der Login-Token wird nicht dauerhaft gespeichert. Es gibt keine Telemetrie und keinen vom Entwickler betriebenen Server für CT-Daten.

    Pro Gruppe sind alle Wege von einem Gruppenstamm zur Gruppe aufgeführt. Ein Klick auf einen Namen im Weg springt in der Übersicht zu dieser Gruppe. Der Gruppenname in der Kopfzeile öffnet die Gruppe zum Bereinigen in CT. 🔒 = Obergruppe ohne Berechtigung.
